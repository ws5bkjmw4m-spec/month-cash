# month-cash

一個可在手機與電腦瀏覽器使用的單頁記帳工具。直接開啟 `index.html` 即可使用。

## 功能

- 為各月份設定可花額度，顯示扣除當月分期、固定支出與平時支出後的剩餘額度；平時支出可按月份查看明細與合計。
- 「現金與帳戶」分頁：設定現金及各帳戶餘額、帳戶互轉、存提款，保留轉移與餘額調整紀錄。來源餘額不足時會阻止轉移。資產餘額跨月份保留，與月度支出獨立計算。
- 記錄每月固定支出。
- 依分期總金額、年利率、期數與首期月份，估算各月信用卡分期金額。
- 下載及匯入 JSON 備份；匯入會合併新資料，不會清除目前的記錄。版本 3 備份包含資產資料，仍可匯入舊版備份。資產紀錄以完整轉移合併，避免重複入帳；若兩個裝置各自新增了不同異動，會阻止整次匯入並保留現有資料。請先分別備份，再核對各裝置餘額。

## 資料與試算

記帳資料只儲存在目前瀏覽器的 localStorage，不會自動同步。清除網站資料或改用其他裝置時，原記錄不會自動出現。JSON 備份含記帳內容，請妥善保存。

分期採年利率 ÷ 12 的每月本息平均攤還估算，並將整數元的差額分配至各期。實際帳單可能因發卡銀行的計息、手續費或四捨五入方式而不同。

## GitHub Pages

將此資料夾的 `index.html`、`assets.js` 與 `assets.css` 放在 `month-cash` 倉庫的根目錄，然後到倉庫 **Settings → Pages**，選擇 **Deploy from a branch**、`main` 與 `/(root)`。發佈後網址通常是 `https://<GitHub 帳號>.github.io/month-cash/`。

GitHub Pages 網站可公開存取；這個倉庫只應放程式檔案，不要加入匯出的個人記帳備份。
